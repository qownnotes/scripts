# Changelog

## 0.0.4 - 2022-01-10

- Import Vivaldi note attachments as Markdown image links.
- Derive a heading from note content when an imported note has no subject.

## 0.0.3 - 2020-11-02

- Allow exporting only the selected notes instead of the entire note tree.
- Validate import paths and JSON before importing and report failures without aborting unexpectedly.

## 0.0.2 - 2020-11-01

- Add export of the complete QOwnNotes folder and note hierarchy to Vivaldi-compatible JSON.
- Raise the minimum QOwnNotes version to 20.11.0.

## 0.0.1 - 2020-10-28

- Add recursive import of Vivaldi notes and folders from the browser's `Notes` JSON file.
