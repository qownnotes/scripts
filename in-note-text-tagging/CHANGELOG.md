# Changelog

## 0.3.0 - 2026-05-07

- Added an option to recognize tags only when they occur at the beginning of a line.

## 0.2.2 - 2026-04-22

- Added independently configurable primary and secondary tag markers.
- Added a configurable maximum tag length and broader Unicode tag-name support.
- Improved adding, removing, renaming, listing, and autocompleting tags when multiple markers are enabled.

## 0.2.0 - 2021-08-04

- Removed preview tag highlighting to avoid corrupting or misidentifying Markdown content.

## 0.1.0 - 2021-07-14

- Corrected tag-detection regular expressions for punctuation and preview edge cases.

## 0.0.9 - 2020-05-31

- Updated preview processing to the newer pre-Markdown HTML hook.

## 0.0.8 - 2018-02-06

- Fixed conversion of spaces and underscores in multi-word tags.

## 0.0.7 - 2018-02-05

- Fixed conversion of tags containing spaces.

## 0.0.6 - 2018-02-03

- Added autocompletion for existing tags while typing in-note tags.

## 0.0.5 - 2017-10-18

- Added an option to place UI-added tags near the beginning of a note instead of at the end.
- Added configurable tag highlighting in the note preview.

## 0.0.4 - 2017-10-08

- Corrected exact tag matching so similarly prefixed tags are not confused.

## 0.0.3 - 2017-10-05

- Fixed renaming and conversion of multi-word tags, including names containing multiple spaces.

## 0.0.2 - 2017-10-04

- Added a configurable tag marker.
- Added multi-word tag support using underscores in note text.

## 0.0.1 - 2017-10-03

- Initial experimental release integrating tags stored directly in note text with QOwnNotes tag operations.
