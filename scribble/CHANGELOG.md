# Changelog

## 0.4 - 2019-10-19

- Fixed legacy-link detection and converted media paths to native separators for Windows editors.

## 0.3 - 2019-10-19

- Added support for both legacy and relative media links when locating the inserted image for editing.
- Raised the minimum QOwnNotes version to 19.10.7.

## 0.2 - 2018-03-06

- Added foreground and background launch modes for the external image editor.
- Refreshed the note preview after synchronous editing and migrated to the media-file insertion API.

## 0.1 - 2018-03-06

- Added insertion of a configurable template image into the media folder and opening it in an external image editor.
