# Changelog

## 0.0.2 - 2021-12-01

- Replaced Pandoc's deprecated `markdown_github` output format with `gfm`.
- Added configurable Pandoc path guidance for Linux, Windows, and macOS.
- Corrected Windows path escaping in the script metadata.

## 0.0.1 - 2017-09-29

- Added a note-editor action that converts clipboard HTML to GitHub Markdown with Pandoc and inserts the result.
