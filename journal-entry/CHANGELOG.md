# Changelog

## 1.8.0 - 2025-04-12

- Added three-character weekday placeholders to journal date formatting.

## 1.7.0 - 2024-10-18

- Added configurable date-based formatting for journal titles.

## 1.6.0 - 2021-09-19

- Added support for QOwnNotes configurations where the note filename may differ from its headline.

## 1.5.1 - 2020-08-15

- Changed the calendar window to a dialog so it can be closed with Escape.

## 1.5.0 - 2020-08-15

- Added a calendar for choosing the journal-entry date.

## 1.4.0 - 2019-03-17

- Added an action to create or open tomorrow's journal entry.

## 1.3.0 - 2019-03-17

- Added an optional body template for newly created journal entries.

## 1.2.0 - 2017-12-17

- Added support for multiple journal entries per day.

## 1.1.1 - 2017-11-30

- Corrected folder placement for newly created journal notes.

## 1.1.0 - 2017-11-30

- Added a setting for the folder in which journal notes are created.

## 1.0.0 - 2017-11-28

- Added automatic tagging of newly created journal entries.

## 0.0.2 - 2017-05-16

- Changed the generated journal filename and improved Setext heading generation.

## 0.1 - 2017-05-16

- Initial release with an action to create or open the current day's journal entry.
