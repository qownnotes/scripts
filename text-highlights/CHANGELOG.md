# Changelog

## 0.0.6 - 2023-03-03

- Improved editor-highlight matching so empty or malformed `==` markers are not treated as highlights.

## 0.0.5 - 2023-03-02

- Added optional highlighting of `==text==` directly in the editor with a configurable style.

## 0.0.4 - 2020-05-31

- Updated preview and export rendering to the current HTML hook signature.

## 0.0.3 - 2018-10-30

- Switched rendered highlights to semantic `<mark>` elements.
- Accepted named colors and standard `#hex` values for the configurable highlight color.

## 0.0.2 - 2018-08-02

- Initial imported release for wrapping selected text in `==` markers and rendering configurable highlights in the preview.
