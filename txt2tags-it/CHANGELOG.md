# Changelog

## 0.1.1 - 2026-05-22

- Restore keyboard focus to the note editor after a txt2tags formatting action.
- Improve URL parsing and cache preview-rendering state used for links and styles.

## 0.1 - 2026-04-22

- Add a Markdown-it renderer with optional txt2tags heading syntax and editor highlighting.
- Add actions for txt2tags italic, strikethrough, underline, and level 1-3 headings.
- Support configurable Markdown-it options, Setext headings, custom preview CSS, and local file links.
