# Changelog

## 0.3.0 - 2026-01-06

- Corrected Mastodon OAuth scopes to the required lowercase `read write profile` values.
- Improved API error logging and corrected authentication and publishing messages.

## 0.2.0 - 2024-11-09

- Repurposed Publish to GoToSocial as Publish to Fediverse for Mastodon-compatible servers.
- Added actions to create frontmatter-backed post notes and publish them after confirmation.
- Added OAuth access-token handling, credential verification, visibility, language, content-warning, local-only, and signature settings.
- Recorded published post metadata in frontmatter and tagged managed and published notes.
