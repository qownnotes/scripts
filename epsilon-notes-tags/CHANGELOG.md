# Changelog

## 0.0.5 - 2020-05-31

- Updated HTML hook integration for compatibility with QOwnNotes 20.6.

## 0.0.4 - 2020-03-13

- Renamed the script to clarify its general YAML tag support and documented compatibility beyond Epsilon Notes.
- Documented selection of either `...` or `---` as the YAML closing delimiter.

## 0.0.3 - 2020-03-12

- Added a setting to use dashes instead of dots as the YAML closing delimiter.

## 0.0.2 - 2018-05-21

- Added a YAML section automatically when assigning a tag to a note without one.

## 0.0.1 - 2018-05-21

- Added reading and writing note tags in an Epsilon Notes-compatible YAML header.
