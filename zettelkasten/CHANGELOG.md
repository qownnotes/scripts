# Changelog

## 0.2.1 - 2026-05-05

- Generate wiki-link targets from note names only so QOwnNotes resolves links regardless of subfolder.
- Expand usage and configuration documentation.

## 0.2.0 - 2026-05-02

- Add configurable timestamp-based Zettelkasten ID generation and detection.
- Add a searchable note picker that inserts `[[filename|ID]]` wiki-links.
- Add automatic and manual repair of stale ID-based backlinks after note renames.
