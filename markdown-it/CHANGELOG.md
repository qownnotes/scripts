# Changelog

## 1.6 - 2026-08-24

- Fix local images and attachments in the preview for both current and legacy link formats ([#77](https://github.com/qownnotes/scripts/issues/77)).

## 1.5 - 2025-05-04

- Add optional LaTeX rendering with the Markdown-It KaTeX plugin ([#266](https://github.com/qownnotes/scripts/pull/266)).

## 1.4 - 2020-05-31

- Update the HTML hook for compatibility with QOwnNotes 20.6.0 ([#99](https://github.com/qownnotes/scripts/pull/99)).
- Document the legacy media-link requirement that applied to this release ([#77](https://github.com/qownnotes/scripts/issues/77)).

## 1.3 - 2019-10-24

- Work around QML's incompatibility with the bundled Node module exports ([#72](https://github.com/qownnotes/scripts/issues/72), [#74](https://github.com/qownnotes/scripts/pull/74)).

## 1.2 - 2018-12-20

- Add optional definition-list support with the Markdown-It definition list plugin ([#48](https://github.com/qownnotes/scripts/issues/48)).

## 1.1.1 - 2018-11-12

- Improve table spacing and cell padding.

## 1.1.0 - 2018-11-12

- Add bordered table styling and disable table cell spacing.
- Update the bundled Markdown-It dependency to version 8.4.2.

## 1.0.1 - 2018-03-30

- Update the script description and usage information.

## 1.0.0 - 2018-03-30

- Add hyperlink support.

## 0.0.1 - 2017-08-09

- Initial release of the Markdown-It renderer.
- Fix character escaping in metadata links.
