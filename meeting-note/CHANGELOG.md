# Changelog

## 1.4.2 - 2024-05-16

- Allowed an empty headline prefix without leaving unwanted whitespace in generated names.

## 1.4.1 - 2023-10-24

- Fixed reloading of the meeting-note window title.

## 1.4.0 - 2020-04-26

- Added support for configurations where note filenames may differ from note headlines.

## 1.3.0 - 2020-04-07

- Added options to enter a custom date string and create a dated subfolder.

## 1.2.0 - 2019-03-17

- Added an optional body template for newly created meeting notes.

## 1.0.1 - 2018-12-10

- Added an option to include the current time in meeting-note names.

## 1.0.0 - 2017-12-05

- Added configurable default tags and a default folder for newly created meeting notes.

## 0.0.1 - 2017-05-19

- Initial release with an action to create or open the current day's meeting note.
