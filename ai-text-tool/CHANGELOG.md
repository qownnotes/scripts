# Changelog

## 0.2.0 - 2024-11-26

- Replaced the result editor with a diff dialog for reviewing AI changes against the selected text.

## 0.1.0 - 2024-05-22

- Added a multiline editor for reviewing and changing AI output before insertion.

## 0.0.4 - 2024-05-22

- Replaced the editable item selector with a dedicated text input for AI results.

## 0.0.3 - 2024-05-22

- Fixed insertion to use the reviewed result instead of the original AI response.

## 0.0.2 - 2024-05-21

- Improved the typo-correction prompt to request only corrected text.
- Added a review step that allows the generated result to be edited or rejected.

## 0.0.1 - 2024-05-18

- Added AI actions to translate selected text to English, summarize it, or fix spelling and grammar.
