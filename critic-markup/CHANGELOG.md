# Changelog

## 0.0.3 - 2020-11-29

- Improved conformance with the Critic Markup specification for replacements, additions, deletions, and highlight metadata.
- Added rendering for paragraph-break additions and deletions.

## 0.0.2 - 2020-11-23

- Added multiline Critic Markup rendering while preserving nested HTML tags.
- Added configurable class prefixes and unique classes for related markup elements.

## 0.0.1 - 2020-11-16

- Added custom actions for comments, additions, deletions, substitutions, and highlights.
- Added configurable preview styling and HTML conversion for Critic Markup syntax.
