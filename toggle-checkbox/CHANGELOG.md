# Changelog

## 1.4.1 - 2023-12-04

- Preserved indentation when toggling checkboxes and converting indented list items.

## 1.4.0 - 2023-11-27

- Prevented list markers embedded later in a line from being converted into checkboxes.

## 1.3.0 - 2023-03-01

- Restored the editor selection after toggling selected lines.

## 1.2.0 - 2021-11-29

- Added the disabled checkbox state (`[-]`) to the toggle cycle.

## 1.1.0 - 2021-10-20

- Added an option to modify only existing checkboxes, leaving plain lines and list items unchanged.

## 1.0.0 - 2019-03-19

- Added selectable behavior for cycling or synchronizing multiple checkbox lines.
- Enabled toggling the current line when no text is selected.

## 0.1.1 - 2019-03-17

- Initial imported release for cycling selected lines between plain lists, unchecked checkboxes, and checked checkboxes.
- Added options for uppercase checkbox markers and synchronizing mixed selections.
