# Changelog

## 1.1.1 - 2023-03-13

- Fixed reading the QOwnNotes `Editor/useTabIndent` setting so indentation detection works correctly.

## 1.1.0 - 2023-03-10

- Added support for the configured indentation style and indentation width.
- Allowed ordering a selected nested checkbox sublist without reordering its parent list.
- Added support for Windows CRLF line endings.

## 1.0.0 - 2023-03-08

- Added actions to sort selected checkbox lines by checked, disabled, and unchecked state.
- Added reverse ordering and selection-preservation settings while retaining nested list structure.
