# Changelog

## 0.0.5 - 2017-06-19

- Added `+tag` parsing when exporting tasks and restored tags when importing them.
- Fixed importing tasks that have no tags.

## 0.0.4 - 2017-06-11

- Added an optional setting to delete Taskwarrior tasks after importing them.
- Preserved the selected note structure and inserted imported tasks beneath their project headings.
- Tightened project and task matching to complete lines.

## 0.0.3 - 2017-06-11

- Added configurable Taskwarrior executable path and verbose logging settings.
- Added nested Markdown-heading support for project names during import and export.
- Raised the minimum QOwnNotes version to 17.06.4.

## 0.0.2 - 2017-06-02

- Added importing Taskwarrior tasks for projects named in the selected text.

## 0.0.1 - 2017-06-02

- Initial release for exporting selected Markdown list items to Taskwarrior projects.
