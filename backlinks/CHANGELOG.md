# Changelog

## 0.0.3 - 2024-06-24

- Fixed backlink matching and generated file URLs on Windows.
- Switched subfolder detection to note-relative directory paths.

## 0.0.2 - 2024-04-29

- Added a setting for extracting backlink titles from ATX or Setext headings.
- Added source paths as tooltips on generated backlink links.

## 0.0.1 - 2021-10-18

- Added discovery and rendering of notes that link to the current note with wiki-style links.
- Added optional backlink regeneration whenever the Markdown preview is rendered.
