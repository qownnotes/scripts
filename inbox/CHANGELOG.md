# Changelog

## 0.2.2 - 2019-05-09

- Fixed URL conversion and Markdown conversion edge cases.
- Fixed inbox process handling and added `.jpeg` image support.

## 0.2.1 - 2017-09-14

- Forced continuous watch mode to run as a single instance.
- Improved note-folder selection and related settings behavior.

## 0.2.0 - 2017-09-13

- Expanded inbox processing for topic folders, attachments, images, saved web pages, and platform-specific thumbnails.
- Reworked configuration and processing feedback.

## 0.1.1 - 2017-09-08

- Fixed inbox folder scanning.

## 0.1.0 - 2017-09-03

- Added Markdown conversion helpers and documented workflow examples.
- Expanded conversion of URLs, files, and captured content into notes.

## 0.0.1 - 2017-08-14

- Initial beta release for processing files collected in an inbox folder into QOwnNotes notes and attachments.
